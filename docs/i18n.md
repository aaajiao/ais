# 国际化 (i18n)

应用通过 `react-i18next` 支持中文（默认）和英文。

---

## 使用方法

```tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation('namespace'); // 如 'common', 'artworks'
  return <p>{t('key.nested')}</p>;
}

// 带插值
t('selected', { count: 5 }) // "已选择 5 项" / "5 selected"
```

---

## 添加翻译

1. 在 `zh/*.json` 和 `en/*.json` 中添加键
2. 在组件中使用 `useTranslation('namespace')`
3. 用 `t('key')` 替换硬编码文本

## 语言切换

- 设置页面中的 `LanguageSwitcher` 组件
- 语言偏好存储在 `localStorage`（`i18nextLng`）
- 首次访问时自动检测浏览器语言

---

## 默认语言选择（首次访问 / 画廊访客）

检测顺序 `['localStorage', 'navigator']`，未登录的公开链接访客（`/view/:token`）按系统语言自动选语言：

| 系统语言 | 显示 |
|----------|------|
| 中文（`zh` / `zh-CN` / `zh-TW` / `zh-HK`） | 中文 |
| 英文（`en` / `en-US` / `en-GB`） | 英文 |
| 其他（德 / 法 / 日 / 韩…） | **英文**（兜底，非中文） |

实现靠 `src/locales/index.ts` 三个选项配合：

- `supportedLngs: ['zh', 'en']` —— 只认两种语言
- `load: 'languageOnly'` + `nonExplicitSupportedLngs: true` —— 把 `en-US`/`zh-CN` 归一到基语言
- `fallbackLng: ['en', 'zh']` —— 未命中时**先回退英文**、中文兜底

> ⚠️ 历史坑：`fallbackLng` 曾为 `'zh'`，导致非中文系统的画廊访客被回退到**中文**（与期望相反）。
> 改回退默认值时务必保持「非中文 → 英文」。守护测试 `src/locales/__tests__/language-detection.test.ts`。

访客一旦手动切换语言，选择写入 `localStorage`（`detection.order` 中 localStorage 优先于 navigator），后续访问永远尊重其选择。
